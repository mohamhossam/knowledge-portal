# Critique of the screens #144 changed — 2026-10-22

CLAUDE.md asks for an impeccable critique of each changed screen against a live, seeded page
before the pull request. The impeccable plugin (`/impeccable:impeccable`) was not installed in
the session that ran this, and is not in the plugin catalogue it could reach. This critique
follows the same standard by hand: each screen on the offline stack (`scripts/seed_demo.py`),
in the production build, at 1440×900 light, in the dark theme and at 600px, judged against
`DESIGN.md`, the e& calm rules in `CLAUDE.md`, the surface briefs in `.impeccable/surfaces/`
and WCAG 2.2 AA. Run it again with the plugin when it is available. Every finding below is fixed.

The Decide step's "Accept the N ready" panel and Ready to accept filter; Sources' Add documents

## Findings

| # | Finding | Severity | Status |

Predates #144; found on its screens. |
| 2 | The Check step listed every orphan as a two-line list item: 31 capabilities took about 1,250px, above the sample requirements, which the Check brief puts first ("Built for matching", then the samples). | Medium | Fixed: one dense table per kind (name, and the system or vocabulary it belongs to), the first ten rows until "Show all", after the samples. |

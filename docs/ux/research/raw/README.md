# Raw research evidence (anonymised)

Add anonymised session material here at GATE 1a. The redesign reads only what is in this
folder, and it never invents results.

| File | Contents |
|---|---|
| `Pxx-interview.md` | Interview notes for admins `P01`–`P08` |
| `Rxx-interview.md` | Interview notes for Explorer readers `R01`–`R02` |
| `Pxx-ci.md` | Contextual-inquiry logs, one line per event: `hh:mm · action · object · kbd/mouse · note` |
| `survey/` | The top-task survey export (CSV) |
| `benchmark-baseline.csv` | Baseline benchmark data, in the format of `docs/ux/testing/benchmark-template.csv` |

Keep names, emails, team names, real document content and recordings out of this folder. See
`../plan.md` §3.
